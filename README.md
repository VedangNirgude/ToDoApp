# Todo App

A simple and responsive Todo List web application built using **HTML, CSS, and JavaScript**. Users can add and delete tasks through an easy-to-use interface, with the task list updating dynamically using JavaScript DOM manipulation.

### Features

* Add new tasks
* Delete tasks
* Display the current number of tasks
* Prevent empty tasks
* Add tasks using the Enter key
* Clean and responsive interface

### Technologies

* HTML5
* CSS3
* JavaScript
* DOM Manipulation
